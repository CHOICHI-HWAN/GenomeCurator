서브서버

이 서버를 메인 서버의 작업을 나누어 처리하는 서브서버로 쓸 수 있습니다. 메인 서버의 클러스터 화면에서 이 서버를 워커로 추가하면 받는 키와 메인 주소가 필요합니다.

서브서버로 참여

참여 요청을 보내면 메인 서버의 클러스터 화면에 승인 대기로 나타납니다. 메인에서 승인하면 이 서버가 스스로 키를 받아 작업을 시작합니다(키를 옮겨 적을 필요 없음). 프로그램을 다시 켜도 유지됩니다.
메인에서 직접 받은 워커 키로 시작

웹 터미널

꺼짐
허용하면 승인한 메인 서버가 브라우저에서 이 서버의 셸을 열 수 있습니다(이 프로그램을 띄운 사용자 권한). 접속마다 메인이 만든 1분짜리 일회용 토큰을 확인하며, 접속 기록이 양쪽 서버에 남습니다(입력 내용은 기록하지 않음). 기본은 꺼짐입니다.
