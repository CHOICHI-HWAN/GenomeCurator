Nextstrain mpox와 쓰는 법

  1. QC 탭에서 mpox의 QC 실행을 합니다 (Nextclade QC 열이 채워집니다. 없으면 워크플로의 기본 필터가 그 행들을 걸러냅니다).
  2. 위에서 서버 폴더에 만들기 → metadata.tsv, sequences.fasta, manifest.json, nextstrain-config.yaml이 생깁니다.
  3. git clone https://github.com/nextstrain/mpox 후 cd mpox/phylogenetic && nextstrain build . --configfile <만든 폴더>/nextstrain-config.yaml

내부 API

GET  /api/export/profiles
GET  /api/export/{virus_id}/preview?profile=nextstrain&min_length=100000&completeness=Complete,Near%20complete&qc_not=bad
GET  /api/export/{virus_id}/metadata.tsv?profile=nextstrain      # TSV
GET  /api/export/{virus_id}/sequences.fasta?profile=nextstrain   # FASTA, ids = INSDC_accession_version
POST /api/export/{virus_id}/build?profile=nextstrain             # 서버 작업: 폴더에 파일 생성 → /api/job/{id}
GET  /api/exports                                                # 만들어 둔 내보내기 목록
