Nextstrain mpox와 쓰는 법

  1. QC 탭에서 mpox의 QC 실행 (Nextclade QC 열이 채워집니다. 없으면 워크플로의 기본 필터가 그 행들을 걸러냅니다).
  2. git clone https://github.com/nextstrain/mpox 후, 체크아웃 안으로 바로 내보내기:
    python -m genomecurator export "Orthopoxvirus monkeypox" --nextstrain-dir ~/mpox/phylogenetic
  3. cd ~/mpox/phylogenetic && nextstrain build . --configfile defaults/mpxv/config.yaml build-configs/genomecurator/config.yaml
    config를 두 개(워크플로 기본값 + 우리 overlay) 줘야 합니다. overlay는 inputs를 로컬 파일로 바꾸고 use_remote_files: false로 웹 다운로드를 끕니다. 워크플로 id는 PPX_accession입니다.

위의 "서버 폴더에 만들기"는 data/exports/에 절대 경로 설정과 함께 만듭니다(Docker 런타임에서는 파일이 보이지 않으니 --nextstrain-dir를 쓰세요).

내부 API

GET  /api/export/profiles
GET  /api/export/{virus_id}/preview?profile=nextstrain&min_length=100000&completeness=Complete,Near%20complete&qc_not=bad
GET  /api/export/{virus_id}/metadata.tsv?profile=nextstrain      # TSV
GET  /api/export/{virus_id}/sequences.fasta?profile=nextstrain   # FASTA, ids = INSDC_accession_version
POST /api/export/{virus_id}/build?profile=nextstrain             # 서버 작업: 폴더에 파일 생성 → /api/job/{id}
GET  /api/exports                                                # 만들어 둔 내보내기 목록
