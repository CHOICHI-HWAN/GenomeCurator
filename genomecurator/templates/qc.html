QC (서열 품질 · Nextclade)

저장된 서열을 한 번 더 검사합니다. 경고만 하고 아무것도 막지 않으며, 큐레이션 값을 몰래 바꾸지 않습니다.
서열 통계(길이, N·모호 염기 비율, GC, 기록된 길이와 일치 여부)는 모든 바이러스에 적용됩니다. Nextclade는 데이터셋이 있는 바이러스에서만 돌며 clade/lineage와 자체 품질 점수를 줍니다. Nextclade가 부른 clade/lineage는 소스 값과 같으면 아무 일도 없고, 소스가 비어 있으면 채울 후보로, 다르면 검토 화면의 "소스 간 불일치"에 Nextclade 값이 함께 올라와 직접 고릅니다 (QC 실행 + 확인 또는 다음 지금 확인 때 반영).
도구: Nextclade {% if tool_ok %}v{{ tool_version }}{% else %}설치 안 됨 — mamba install -c bioconda nextclade (또는 environment.yml로 환경 다시 만들기). 설치 전에는 서열 통계만 돕니다.{% endif %} · 서열 통계: 내장 · CheckV {% if checkv.ok %}v{{ checkv.version }} (DB {{ checkv.db.split('/')[-1] }}){% elif checkv.env %}데이터베이스 없음 — {{ checkv.how }}{% else %}없음 — mamba env create -f variantcall/checkv.yml 후 데이터베이스 받기(약 1.5 GB){% endif %} · Squirrel QC: 최근 끝난 Squirrel 실행의 판정을 QC 실행 때 함께 저장 (아래 카드)
우선순위: Squirrel > Nextclade > CheckV (그다음 내장 서열 통계). 한 유전체의 대표 QC 상태(유전체 표의 QC 열, 데이터셋 QC 제외 규칙)는 결과가 있는 가장 우선순위 높은 도구의 판정을 따릅니다. 다른 도구의 판정도 그대로 보이며 아무것도 숨기지 않습니다.
